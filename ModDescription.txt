[center][h1]SimpleShop - 简单商店[/h1][/center]

[h2]简介[/h2]
SimpleShop 是一个轻松实用的购物mod，为玩家提供便捷的商店界面来购买各种游戏物品。本mod参考了CoxisShop并进行了简化设计，专门专注于物品购买功能，让您在末世中能够更轻松地获取所需物资。商品列表完全兼容其他mod物品，即使物品不存在也没关系，mod会自动检测确保只显示当前游戏中存在的物品。设计简洁直观，方便与其他mod配合使用，为您带来更好的游戏体验。

[h2]主要功能[/h2]
[list]
    [*] 商店界面 - 滚动列表显示物品，支持分类筛选、搜索与排序
    [*] 商品顺序管理 - 管理员用"置顶/上移/下移/置底"自定义商品陈列顺序，商店按该顺序展示，顺序随存档保存
    [*] 货币系统 - 通过击杀僵尸获得金钱
    [*] 死亡继承 - 玩家死亡后保留全部金钱
    [*] 右键菜单 - 在世界界面或物品栏中右键点击，选择"打开商店"
    [*] 可配置快捷键 - 打开商店与商品管理都能自定义按键，默认不绑定，不与游戏既有键位冲突
    [*] 多语言支持 - 内置中英文界面
    [*] 可配置 - 支持自定义初始金钱和物品价格
    [*] 游戏内定价 - 管理员可从全部物品脚本（含其他模组物品）中挑选物品并设定售价，无需改代码
    [*] 价格持久化 - 价格表随存档保存，退出游戏或重启后依然生效
[/list]

[h2]如何使用[/h2]
[list]
    [*] 打开商店：在世界界面或物品栏中右键点击，选择"打开商店"；也可在 选项 → 按键设置 里为"打开商店"绑定快捷键（默认不设置）
    [*] 购买物品：打开商店界面，点击要购买的物品，然后点击"购买"按钮
    [*] 搜索物品：使用搜索框快速查找所需物品
    [*] 分类筛选：使用下拉菜单按类别浏览物品
    [*] 排序商品：排序下拉框默认是"商店顺序"（管理员设定的陈列顺序），也可临时切换 名称 A→Z / 名称 Z→A / 价格 低→高 / 价格 高→低，可与搜索、分类筛选叠加；下拉框右侧显示当前结果数量
    [*] 获得金钱：击杀僵尸可获得金钱奖励，新角色开始时有初始资金
    [*] 商品定价：点击商店底部"定价"按钮（也可为"管理商品"绑定快捷键，默认不设置），可按名称/ID 搜索、按来源模组与物品类型两级筛选、切换排序、分页浏览，选中物品输入价格后点"上架/改价"
    [*] 调整商品顺序：在定价窗口选中已上架商品，点顶部"置顶 / 上移 / 下移 / 置底"调整它在商店里的位置；新上架商品自动排到末尾，下架自动移出顺序
    [*] 快捷键：打开商店、管理商品（定价+顺序）都可在 选项 → 按键设置 里绑定到自己顺手的按键，默认不设置；聊天/输入框打字时不会误触发
[/list]

[h3]游戏内定价说明[/h3]
[list]
    [*] 权限：需要管理员权限，单人存档默认即为管理员，可直接使用
    [*] 两种视图：默认显示"已上架商品"（带"已上架"标记与当前价格，选中即可改价）；切换到"全部物品"可浏览全部物品脚本，包括其他模组新增的物品（模组内部的 xxx_Hidden 变体与隐藏/废弃物品已自动排除）
    [*] 查找物品：支持按名称或物品 ID（如 Base.Axe）搜索；两级筛选先按来源模组、再按物品类型（第二个下拉只列出所选模组的类型）；列表按页翻动，物品数量再多也不会卡顿或漏项
    [*] 排序：第三个下拉默认是"商店顺序"（即下面调整好的陈列顺序），也可切换 名称 A→Z / 名称 Z→A / 价格 低→高 / 价格 高→低，按价格排序时未上架的物品统一排在最后
    [*] 调整顺序：选中已上架商品后点顶部"置顶 / 上移 / 下移 / 置底"，列表会显示 1. 2. 3. 序号，改完立刻同步到所有玩家的商店；"恢复默认"会同时清空自定义顺序回到按名称排列
    [*] 价格范围：0 ~ 999999 的整数，0 表示免费
    [*] 下架 / 恢复默认：可将单个物品移出商店，或一键恢复为 SimpleShopItems.lua 的初始清单
    [*] 数据存储：价格表与商品陈列顺序保存在世界级全局 ModData 中，随存档持久化；购买时按该价格表扣款
[/list]

[b]自定义物品[/b]
商店支持添加来自其他mod的物品，即使物品不存在也没关系，mod会自动检测只显示存在的物品。要添加新物品到商店，有两种方式：

1. 推荐：进入游戏后用管理员身份打开商店 → 点击底部"定价"按钮 → 切换到"全部物品" → 搜索 / 选择来源模组与物品类型 / 翻页找到目标物品 → 选中后输入价格 → 点击"上架/改价"。价格会保存在存档中，无需改代码，也不需要重启游戏。已上架的商品可以在"已上架商品"视图里直接选中并改价或下架。
2. 修改SimpleShopItems.lua（作为默认清单，仅在首次创建价格表或"恢复默认"时生效）：

[code]
["物品ID"] = 价格, -- 物品名称
[/code]

游戏原版物品ID可以在PZ Wiki查看：[url=https://pzwiki.net/wiki/Item]https://pzwiki.net/wiki/Item[/url]

[b]创建自定义配置模组[/b]
为了避免在模组更新时丢失配置，建议创建一个单独的配置模组：

1. 创建一个新的模组文件夹
2. 在其中创建以下文件结构：
[code]
MyShopConfig/
├── 42/
│   └── mod.info
└── common/
    └── media/
        └── lua/
            └── shared/
                ├── SimpleShopBasic.lua
                └── SimpleShopItems.lua
[/code]

注意：为了兼容游戏的B42版本，需要创建42版本的文件夹。mod.info文件只需要放在42文件夹内。

3. 在mod.info中添加：
[code]
name=My Shop Config
id=MyShopConfig
require=\SimpleShop
description=Custom configuration for SimpleShop
poster=poster.png
[/code]

4. 在你的配置文件中覆盖所需值：
[code]
-- SimpleShopBasic.lua
SimpleShopBasic = {
    ["initialMoney"] = 100, -- 初始金钱
    ["zombieKillAmount"] = 10, -- 每击杀一个僵尸获得的金钱
}

-- SimpleShopItems.lua
SimpleShopItems = {
    -- 你的自定义物品价格
    ["Base.Bread"] = 50, -- 面包
    ["Base.CustomItem"] = 250, -- 自定义物品
}
[/code]

5. 确保在游戏启动器中，你的配置模组位于SimpleShop之后加载

这种方法可以让你在保持模组更新的同时保留自定义配置。

[h2]API接口[/h2]
SimpleShop提供了以下API，供其他mod调用以修改玩家金钱：

[h3]获取玩家金额[/h3]
[code]
local money = SimpleShop.GetPlayerMoney(playerIndex)
[/code]
获取指定玩家的当前金额，不指定playerIndex则获取当前玩家金额。

[h3]增加玩家金额[/h3]
[code]
SimpleShop.AddPlayerMoney(amount, playerIndex)
[/code]
为指定玩家增加金额，amount必须为正数。

[h3]减少玩家金额[/h3]
[code]
SimpleShop.RemovePlayerMoney(amount, playerIndex)
[/code]
从指定玩家扣除金额，amount必须为正数且玩家余额必须足够。

[h3]检查玩家金额[/h3]
[code]
SimpleShop.HasEnoughMoney(amount, playerIndex)
[/code]
检查指定玩家是否有足够金额。

这些方法可用于实现任务奖励、自定义商店等需要修改玩家金钱的功能。

[h3]商品价格表[/h3]
[code]
-- 读取 / 查询
local prices = SimpleShopItemStore.getPrices()      -- { ["Base.Axe"] = 120, ... }
local cost   = SimpleShopItemStore.getPrice("Base.Axe")
local count  = SimpleShopItemStore.getCount()

-- 修改（建议直接在商店内的定价界面操作）
SimpleShopItemStore.setPrice("Base.Axe", 120)        -- 返回 true 表示成功
SimpleShopItemStore.removePrice("Base.Axe")          -- 下架
SimpleShopItemStore.resetToDefault()                 -- 恢复 SimpleShopItems.lua 默认清单

-- 价格变化监听（界面自动刷新用）
SimpleShopItemStore.addListener(function() ... end)
[/code]
价格会被校验为 0 ~ 999999 的整数，非法值直接返回 false / nil；修改后自动写入全局 ModData，随存档一起保存。

[h2]Introduction[/h2]
SimpleShop is a practical and user-friendly shopping mod that provides players with a convenient shop interface to purchase various items in the game. Based on CoxisShop and redesigned with simplicity in mind, this mod focuses solely on purchasing functionality, helping you easily obtain essential supplies in the post-apocalyptic world. The item list fully supports items from other mods, and even if items don't exist, it doesn't matter - the mod will automatically detect and ensure only existing items are displayed. Its straightforward design makes it compatible with other mods, enhancing your overall gaming experience.

[h2]Key Features[/h2]
[list]
    [*] Shop interface - Scrollable list display with category filtering, search and sorting
    [*] Custom item order - Admins reorder items with the "Top / Up / Down / Bottom" buttons and the shop shows them in that order; the order is saved with the world
    [*] Currency system - Earn money by killing zombies
    [*] Death inheritance - Keep all money after player death
    [*] Right-click menu - Right-click in the world or inventory and select "Open Shop"
    [*] Configurable key binds - Bind keys for opening the shop and for item management; nothing is bound by default
    [*] Multi-language support - Built-in Chinese and English interface
    [*] Configurable - Support for custom initial money and item prices
    [*] In-game pricing - Admins can pick any item script (including items added by other mods) and set its price
    [*] Persistent prices - The price table is saved with the world and kept after quitting or restarting
[/list]

[h2]How to Use[/h2]
[list]
    [*] Open shop: Right-click in the world or inventory and select "Open Shop", or bind your own key in Options → Key Bindings (unbound by default)
    [*] Purchase items: Open the shop interface, click the item you want to buy, then click the "Buy" button
    [*] Search items: Use the search box to quickly find items you need
    [*] Category filter: Use the dropdown menu to browse items by category
    [*] Sort items: The sort dropdown defaults to "Shop order" (the order admins configured) and can be switched to Name A→Z / Z→A / Price low→high / high→low
    [*] Earn money: Get money rewards by killing zombies, new characters start with initial funds
    [*] Pricing: Click the "Pricing" button at the bottom of the shop (or bind a key for "Manage items", unbound by default); search by name / ID, filter by source mod and item type, and page through the list, then choose an item, type a price and click "Set"
    [*] Reorder items: Select a listed item and use "Top / Up / Down / Bottom" at the top of the pricing window; newly listed items are appended to the end and delisted items are dropped from the order
    [*] Shortcuts: Both "Open shop" and "Manage items" can be bound in Options → Key Bindings (nothing is bound by default); keys are ignored while typing in chat or text boxes
[/list]

[h3]About In-Game Pricing[/h3]
[list]
    [*] Permission: Requires admin access; a singleplayer save is admin by default, so it works right away
    [*] Two views: "Listed" (default) shows what is currently on sale with a "Listed" badge and its price, so you can select it and change the price; switch to "All items" to browse every item script, including items added by other mods
    [*] Finding items: Search by display name or item ID (e.g. Base.Axe); two-level filtering picks the source mod first, then the item type (the second dropdown only lists types that exist in that mod); results are paged - large item sets stay fast and nothing is skipped
    [*] Price range: Integer from 0 to 999999 (0 means free)
    [*] Sorting: The third dropdown defaults to "Shop order" (the order you configured below) and can be switched to Name A→Z / Z→A / Price low→high / high→low; unlisted items always sort last in price modes
    [*] Reordering: Select a listed item and use "Top / Up / Down / Bottom"; the list shows 1. 2. 3. indices and every player's shop updates immediately; "Reset Default" also clears the custom order and goes back to name order
    [*] Remove / Reset: Remove a single item from the shop, or restore the default list from SimpleShopItems.lua
    [*] Storage: Prices and the custom item order live in a world-level global ModData entry, so they persist across sessions; purchases are charged from that same table
[/list]

[b]Adding Custom Items[/b]
The shop supports adding items from other mods, and even if items don't exist, it's not a problem - the mod will automatically detect and only display existing items. To add new items to the shop, simply add a new line in SimpleShopItems.lua:
[code]
["ItemID"] = Price, -- Item Name
[/code]

Vanilla game item IDs can be found on the PZ Wiki: [url=https://pzwiki.net/wiki/Item]https://pzwiki.net/wiki/Item[/url]

[b]Creating a Custom Configuration Mod[/b]
To avoid losing configurations when the mod updates, it's recommended to create a separate configuration mod:

1. Create a new mod folder
2. Create the following file structure within it:
[code]
MyShopConfig/
├── 42/
│   └── mod.info
└── common/
    └── media/
        └── lua/
            └── shared/
                ├── SimpleShopBasic.lua
                └── SimpleShopItems.lua
[/code]

Note: To ensure compatibility with game version B42, you need to create a 42 folder. The mod.info file only needs to be placed in the 42 folder.

3. Add to mod.info:
[code]
name=My Shop Config
id=MyShopConfig
require=\SimpleShop
description=Custom configuration for SimpleShop
poster=poster.png
[/code]

4. Override needed values in your configuration files:
[code]
-- SimpleShopBasic.lua
SimpleShopBasic = {
    ["initialMoney"] = 100, -- Initial money
    ["zombieKillAmount"] = 10, -- Money earned per zombie kill
}

-- SimpleShopItems.lua
SimpleShopItems = {
    -- Your custom item prices
    ["Base.Bread"] = 50, -- Bread
    ["Base.CustomItem"] = 250, -- Custom item
}
[/code]

5. Make sure your configuration mod loads after SimpleShop in the game launcher

This method allows you to keep your custom configurations while maintaining mod updates.

[h2]API Interface[/h2]
SimpleShop provides the following APIs for other mods to call to modify player money:

[h3]Get Player Money[/h3]
[code]
local money = SimpleShop.GetPlayerMoney(playerIndex)
[/code]
Get the current amount of money for the specified player, or get the current player's money if playerIndex is not specified.

[h3]Add Player Money[/h3]
[code]
SimpleShop.AddPlayerMoney(amount, playerIndex)
[/code]
Add money to the specified player, amount must be a positive number.

[h3]Remove Player Money[/h3]
[code]
SimpleShop.RemovePlayerMoney(amount, playerIndex)
[/code]
Deduct money from the specified player, amount must be a positive number and the player must have sufficient balance.

[h3]Check Player Money[/h3]
[code]
SimpleShop.HasEnoughMoney(amount, playerIndex)
[/code]
Check if the specified player has enough money.

These methods can be used to implement features such as quest rewards, custom shops, or any functionality that requires modifying player money.

[h3]Item Price Table[/h3]
[code]
-- Read / query
local prices = SimpleShopItemStore.getPrices()      -- { ["Base.Axe"] = 120, ... }
local cost   = SimpleShopItemStore.getPrice("Base.Axe")
local count  = SimpleShopItemStore.getCount()

-- Modify (using the in-game pricing window is recommended)
SimpleShopItemStore.setPrice("Base.Axe", 120)        -- returns true on success
SimpleShopItemStore.removePrice("Base.Axe")          -- remove from shop
SimpleShopItemStore.resetToDefault()                 -- restore the SimpleShopItems.lua list

-- Price change listener (used to auto-refresh the UI)
SimpleShopItemStore.addListener(function() ... end)
[/code]
Prices are validated as integers between 0 and 999999; invalid values return false / nil. Changes are written into the world-level global ModData and saved together with the world.
