[center][h1]SimpleShop - 简单商店[/h1][/center]

[h2]简介[/h2]
SimpleShop 是一个简洁的购物 mod，参考 CoxisShop 简化而来，专注物品购买。商品列表兼容其他 mod 物品（不存在的物品自动过滤），价格表随存档持久化，并可在游戏内直接定价。

[h2]主要功能[/h2]
[list]
    [*] 商店界面 - 滚动列表显示物品，支持分类筛选、搜索与排序
    [*] 游戏内定价 - 管理员从全部物品脚本（含其他 mod）中挑选物品设价，无需改代码
    [*] 商品顺序 - 定价窗口里"置顶/上移/下移/置底"自定义陈列顺序，随存档保存
    [*] 货币系统 - 击杀僵尸获得金钱，死亡后保留全部金钱
    [*] 打开方式 - 右键"打开商店"，或在 选项 → 模组 → 简易商店 里绑定快捷键
    [*] 权限控制 - 沙箱选项决定是否允许配置商品，玩家可自行决定是否显示"管理商品"按钮
    [*] 可配置 - 初始金钱、击杀奖励、默认物品清单；内置中英文界面
[/list]

[h2]如何使用[/h2]
[list]
    [*] 打开商店：世界界面或物品栏右键"打开商店"，也可用快捷键（默认不绑定）
    [*] 购买：点选物品后点"购买"
    [*] 筛选/排序：分类下拉 + 搜索框 + 排序下拉（默认"商店顺序"，可切名称/价格），三者可叠加
    [*] 获得金钱：击杀僵尸有奖励，新角色有初始资金，死亡不丢钱
    [*] 商品定价：先在沙箱选项开启「简易商店 → 允许配置商品」，并在 选项 → 模组 → 简易商店 勾选「显示管理按钮」（或用快捷键），再点商店底部"管理商品"
[/list]

[h3]定价窗口说明[/h3]
[list]
    [*] 视图：默认"已上架商品"（带价格，选中即可改价）；切到"全部物品"可浏览全部脚本（自动排除隐藏/废弃物品与 xxx_Hidden 变体）
    [*] 查找：按名称或 ID 搜索；先选来源模组、再选物品类型；结果分页，物品再多也不卡
    [*] 排序：可切 商店顺序 / 名称 A→Z / 名称 Z→A / 价格 低→高 / 价格 高→低（按价格时未上架排最后）
    [*] 顺序：选中已上架商品用"置顶/上移/下移/置底"调整，改完立刻同步；"恢复默认"同时清空自定义顺序
    [*] 价格：0 ~ 999999 的整数，0 表示免费；可单个下架，也可一键恢复默认清单
    [*] 存储：价格表与陈列顺序保存在世界级全局 ModData，随存档持久化，购买按该表扣款
[/list]

[h2]配置选项[/h2]
[list]
    [*] 初始金钱 100、击杀奖励 10（见 SimpleShopBasic.lua）
    [*] 沙箱选项 - 允许配置商品（默认关闭；联机时为服务端权威校验）
    [*] 模组选项 - 显示「管理商品」按钮、打开商店/管理商品快捷键（默认关闭/不绑定，改完立即生效）
    [*] 默认商品清单 - SimpleShopItems.lua（仅首次建表或"恢复默认"时生效）
[/list]

配置文件位于：[code]SimpleShop/common/media/lua/shared/[/code]

[b]基础配置 (SimpleShopBasic.lua)[/b]
[code]
SimpleShopBasic = {
    \["initialMoney"\] = 100, -- 新角色初始金钱
    \["zombieKillAmount"\] = 10, -- 每击杀一个僵尸获得的金钱
}
[/code]

[b]默认物品清单 (SimpleShopItems.lua)[/b]
[color=#999999]提示：游戏内定价后以存档中的价格表为准；本文件仅在首次创建价格表或点击"恢复默认"时使用。[/color]
[code]
SimpleShopItems = {
    \["Base.Bread"\] = 75,               -- 面包
    \["Base.Apple"\] = 25,               -- 苹果
    \["Base.Axe"\] = 500,                -- 斧头
    \["Base.Bandage"\] = 150,            -- 绷带
    \["Base.Bullets9mmBox"\] = 100,      -- 9mm子弹盒
    \["Base.308Box"\] = 300,             -- .308子弹盒
    ...
}
[/code]
完整清单见文件；添加物品只需按 \["物品ID"\] = 价格 追加一行，物品不存在会被自动忽略。原版物品 ID 见 [url=https://pzwiki.net/wiki/Item]PZ Wiki[/url]。

[h3]推荐：单独的配置模组[/h3]
把 SimpleShopBasic.lua / SimpleShopItems.lua 放进独立模组（[b]42/mod.info[/b] + [b]common/media/lua/shared/[/b]），mod.info 里写 [b]require=\SimpleShop[/b]，并让它在加载顺序里排在 SimpleShop 之后。这样更新本 mod 时自己的配置不会丢。

[h2]API 接口[/h2]
[code]
SimpleShop.GetPlayerMoney(playerIndex)            -- 查询金额
SimpleShop.AddPlayerMoney(amount, playerIndex)    -- 加钱（amount > 0）
SimpleShop.RemovePlayerMoney(amount, playerIndex) -- 扣钱（余额需足够）
SimpleShop.HasEnoughMoney(amount, playerIndex)    -- 是否够
[/code]

[h3]价格表[/h3]
[code]
SimpleShopItemStore.getPrices() / getPrice(id) / getCount()
SimpleShopItemStore.setPrice(id, 120)   -- 返回 true 表示成功
SimpleShopItemStore.removePrice(id)     -- 下架
SimpleShopItemStore.resetToDefault()    -- 恢复默认清单
SimpleShopItemStore.addListener(fn)     -- 价格变化监听（界面刷新用）
[/code]
价格校验为 0 ~ 999999 的整数，非法值返回 false / nil；修改自动写入全局 ModData，随存档保存。

[h2]Introduction[/h2]
SimpleShop is a lightweight shopping mod based on CoxisShop, focused on buying items. The item list supports items from other mods (missing items are filtered out automatically), and the price table is saved with the world and can be edited in-game.

[h2]Key Features[/h2]
[list]
    [*] Shop interface - Scrollable list with category filtering, search and sorting
    [*] In-game pricing - Admins pick any item script (including other mods' items) and set a price, no code needed
    [*] Custom item order - Reorder items with "Top / Up / Down / Bottom" in the pricing window; saved with the world
    [*] Currency system - Earn money by killing zombies, keep it all after death
    [*] How to open - Right-click "Open Shop", or bind a key in Options -> Mods -> SimpleShop
    [*] Permission control - A sandbox option decides whether item configuration is allowed; each player chooses whether to show the "Manage Items" button
    [*] Configurable - Initial money, kill reward, default item list; Chinese and English built in
[/list]

[h2]How to Use[/h2]
[list]
    [*] Open shop: right-click "Open Shop" in the world or inventory, or use your key bind (unbound by default)
    [*] Purchase: select an item and click "Buy"
    [*] Filter / sort: category dropdown + search box + sort dropdown (defaults to "Shop order", switchable to name/price); they stack
    [*] Earn money: kill zombies for rewards, new characters start with funds, death keeps your money
    [*] Pricing: enable the sandbox option "SimpleShop -> Allow item configuration", tick "Show Manage Items button" in Options -> Mods -> SimpleShop (or use the key bind), then click "Manage Items" at the bottom of the shop
[/list]

[h3]About the Pricing Window[/h3]
[list]
    [*] Views: "Listed" (default) shows what is on sale with its price, select to reprice; switch to "All items" to browse every item script (hidden/obsolete items and xxx_Hidden variants are excluded)
    [*] Finding items: search by name or ID; pick the source mod first, then the item type; results are paged, so large item sets stay fast
    [*] Sorting: Shop order / Name A->Z / Z->A / Price low->high / high->low (unlisted items sort last in price modes)
    [*] Reordering: select a listed item and use "Top / Up / Down / Bottom"; changes sync immediately; "Reset Default" also clears the custom order
    [*] Price: integer from 0 to 999999 (0 means free); delist single items or restore the default list
    [*] Storage: prices and order live in a world-level global ModData entry, saved with the world; purchases are charged from it
[/list]

[h2]Configuration Options[/h2]
[list]
    [*] Initial money 100 and kill reward 10 (see SimpleShopBasic.lua)
    [*] Sandbox option - Allow item configuration (off by default; server-authoritative in multiplayer)
    [*] Mod options - Show "Manage Items" button, key binds for opening the shop / managing items (off / unbound by default, applied immediately)
    [*] Default item list - SimpleShopItems.lua (used only when the table is first created or "Reset Default" is clicked)
[/list]

Configuration files are located at: [code]SimpleShop/common/media/lua/shared/[/code]

[b]Basic Configuration (SimpleShopBasic.lua)[/b]
[code]
SimpleShopBasic = {
    \["initialMoney"\] = 100, -- Initial money for new characters
    \["zombieKillAmount"\] = 10, -- Money earned per zombie kill
}
[/code]

[b]Default Item List (SimpleShopItems.lua)[/b]
[color=#999999]Note: after in-game pricing is used, the price table in the world save takes priority; this file is only used when the table is first created or "Reset Default" is clicked.[/color]
[code]
SimpleShopItems = {
    \["Base.Bread"\] = 75,               -- Bread
    \["Base.Apple"\] = 25,               -- Apple
    \["Base.Axe"\] = 500,                -- Axe
    \["Base.Bandage"\] = 150,            -- Bandage
    \["Base.Bullets9mmBox"\] = 100,      -- 9mm Bullet Box
    \["Base.308Box"\] = 300,             -- .308 Box
    ...
}
[/code]
See the file for the full list; to add an item just append \["ItemID"\] = Price - missing items are ignored automatically. Vanilla item IDs: [url=https://pzwiki.net/wiki/Item]PZ Wiki[/url].

[h3]Recommended: a Separate Config Mod[/h3]
Put SimpleShopBasic.lua / SimpleShopItems.lua into your own mod ([b]42/mod.info[/b] + [b]common/media/lua/shared/[/b]), add [b]require=\SimpleShop[/b] to mod.info, and load it after SimpleShop. Your configuration then survives mod updates.

[h2]API Interface[/h2]
[code]
SimpleShop.GetPlayerMoney(playerIndex)            -- query money
SimpleShop.AddPlayerMoney(amount, playerIndex)    -- add (amount > 0)
SimpleShop.RemovePlayerMoney(amount, playerIndex) -- remove (needs enough balance)
SimpleShop.HasEnoughMoney(amount, playerIndex)    -- check
[/code]

[h3]Price Table[/h3]
[code]
SimpleShopItemStore.getPrices() / getPrice(id) / getCount()
SimpleShopItemStore.setPrice(id, 120)   -- returns true on success
SimpleShopItemStore.removePrice(id)     -- delist
SimpleShopItemStore.resetToDefault()    -- restore the default list
SimpleShopItemStore.addListener(fn)     -- price change listener (UI refresh)
[/code]
Prices are validated as integers from 0 to 999999; invalid values return false / nil. Changes are written into the world-level global ModData and saved with the world.
