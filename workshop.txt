title=SimpleShop
description=[h2]Introduction[/h2]
description=SimpleShop is a practical and user-friendly shopping mod that provides players with a convenient shop interface to purchase various items in the game. Based on CoxisShop and redesigned with simplicity in mind, this mod focuses solely on purchasing functionality, helping you easily obtain essential supplies in the post-apocalyptic world. The item list fully supports items from other mods, and even if items don't exist, it doesn't matter - the mod will automatically detect and ensure only existing items are displayed. Its straightforward design makes it compatible with other mods, enhancing your overall gaming experience.
description=
description=[h2]Key Features[/h2]
description=[list]
description=    [*] Shop interface - Scrollable list display with category filtering, search and sorting (name / price, ascending or descending)
description=    [*] Custom item order - Admins reorder items with the "Top / Up / Down / Bottom" buttons and the shop shows them in that order; the order is saved with the world
description=    [*] Currency system - Earn money by killing zombies
description=    [*] Death inheritance - Keep all money after player death
description=    [*] Floating balance - A small always-on-screen balance panel (shopping cart icon on the left); click it to open the shop and drag it anywhere
description=    [*] Right-click menu - Optional (off by default): right-click in the world or inventory and select "Open Shop"
description=    [*] Configurable key binds - Bind keys for opening the shop and for item management in Options -> Mods -> SimpleShop; nothing is bound by default
description=    [*] Sandbox options - Allow item configuration is a world-level sandbox setting (off by default); each player can additionally toggle the "Manage Items" button in Options -> Mods -> SimpleShop
description=    [*] Multi-language support - Built-in Chinese and English interface
description=    [*] Configurable - Starting money and kill reward are sandbox options (default 0 / 10); item prices are set in-game
description=[/list]
description=
description=[h2]How to Use[/h2]
description=[list]
description=    [*] Open shop: left-click the floating balance panel, or bind your own key / enable the right-click menu in Options -> Mods -> SimpleShop
description=    [*] Floating balance panel: sits at the right side of the screen by default; left-click to open/close the shop, drag it to move (the position is saved with your character)
description=    [*] Purchase items: Open the shop interface, click the item you want to buy, then click the "Buy" button
description=    [*] Search items: Use the search box to quickly find items you need
description=    [*] Category filter: Use the dropdown menu to browse items by category
description=    [*] Sort items: Use the sort dropdown to switch between Shop order (default, configured by admins) / Name A→Z / Name Z→A / Price low→high / Price high→low; sorting stacks with search and category filters
description=    [*] Reorder items: In the pricing window select a listed item and press "Top / Up / Down / Bottom"; new listings are appended to the end and delisted items are removed from the order
description=    [*] Earn money: Get money rewards by killing zombies (10 per kill by default); a new character starts with the amount set by the sandbox option (0 by default)
description=[/list]
description=
description=[h2]Configuration Options[/h2]
description=[list]
description=    [*] Sandbox options (world settings page "SimpleShop"): starting money for new characters (default 0), kill reward (default 10; 0 disables), allow item configuration and price table scope
description=    [*] Server-authoritative in multiplayer and synced to clients; starting money only affects characters without a money record yet
description=    [*] Purchasable items: Including basic survival supplies, medical supplies, tools, weapons, building materials, and ammunition
description=    [*] Mod options: floating balance panel (on), "Open Shop" right-click entry (off), Manage Items button (off) and key binds are all configured in Options -> Mods -> SimpleShop
description=[/list]
description=
description=[h3]Configuration Files Location[/h3]
description=Mod configuration files are located at: [code]SimpleShop/common/media/lua/shared/[/code]
description=
description=[b]Sandbox options (world settings)[/b]
description=Starting money for new characters, kill reward, allow item configuration and price table scope are configured on the "SimpleShop" page of the sandbox options. In multiplayer the server is authoritative and syncs them to clients; starting money only affects characters without a money record yet.
description=SimpleShopBasic.lua keeps the same fields only as a fallback (used when the sandbox option is missing), so tune the sandbox options instead.
description=
description=[b]Item Price Configuration (SimpleShopItems.lua)[/b]
description=The full default list lives in SimpleShop/common/media/lua/shared/SimpleShopItems.lua. Prices changed in game are stored in the active price table and take priority; the file only seeds the first load or "Reset Default".
description=
description=[b]Adding Custom Items[/b]
description=The shop supports adding items from other mods, and even if items don't exist, it's not a problem - the mod will automatically detect and only display existing items. To add new items to the shop, simply add a new line in SimpleShopItems.lua:
description=[code]
description=["ItemID"] = Price, -- Item Name
description=[/code]
description=
description=Vanilla game item IDs can be found on the PZ Wiki: [url=https://pzwiki.net/wiki/Item]https://pzwiki.net/wiki/Item[/url]
description=
description=[b]Creating a Custom Configuration Mod[/b]
description=To avoid losing configurations when the mod updates, it's recommended to create a separate configuration mod:
description=
description=1. Create a new mod folder
description=2. Create the following file structure within it:
description=[code]
description=MyShopConfig/
description=├── 42/
description=│   └── mod.info
description=└── common/
description=    └── media/
description=        └── lua/
description=            └── shared/
description=                └── SimpleShopItems.lua
description=[/code]
description=
description=Note: To ensure compatibility with game version B42, you need to create a 42 folder. The mod.info file only needs to be placed in the 42 folder.
description=
description=3. Add to mod.info:
description=[code]
description=name=My Shop Config
description=id=MyShopConfig
description=require=\SimpleShop
description=Custom configuration for SimpleShop
description=poster=poster.png
description=[/code]
description=
description=4. Override the default item prices (money settings live in the world's sandbox options):
description=[code]
description=-- SimpleShopItems.lua
description=SimpleShopItems = {
description=    -- Your custom item prices
description=    ["Base.Bread"] = 50, -- Bread
description=    ["Base.CustomItem"] = 250, -- Custom item
description=}
description=[/code]
description=
description=5. Make sure your configuration mod loads after SimpleShop in the game launcher
description=
description=This method allows you to keep your custom configurations while maintaining mod updates.
description=
description=[h2]API Interface[/h2]
description=SimpleShop provides the following APIs for other mods to call to modify player money:
description=
description=[h3]Get Player Money[/h3]
description=[code]
description=local money = SimpleShop.GetPlayerMoney(playerIndex)
description=[/code]
description=Get the current amount of money for the specified player, or get the current player's money if playerIndex is not specified.
description=
description=[h3]Add Player Money[/h3]
description=[code]
description=SimpleShop.AddPlayerMoney(amount, playerIndex)
description=[/code]
description=Add money to the specified player, amount must be a positive number.
description=
description=[h3]Remove Player Money[/h3]
description=[code]
description=SimpleShop.RemovePlayerMoney(amount, playerIndex)
description=[/code]
description=Deduct money from the specified player, amount must be a positive number and the player must have sufficient balance.
description=
description=[h3]Check Player Money[/h3]
description=[code]
description=SimpleShop.HasEnoughMoney(amount, playerIndex)
description=[/code]
description=Check if the specified player has enough money.
description=
description=These methods can be used to implement features such as quest rewards, custom shops, or any functionality that requires modifying player money.
