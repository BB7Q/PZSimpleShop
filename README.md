# SimpleShop - Project Zomboid Mod

一个简单的商店模组，让玩家可以在游戏中购买物品。

## 项目简介

SimpleShop 是一个简单的购物mod，为玩家提供了商店界面用于购买游戏中的各种物品。本mod只能用来购买物品，不包含其他功能。本mod参考了CoxisShop，并进行了功能简化和重新设计，使其更加轻量化和易于使用。设计简洁，方便扩展和集成到其他mod中。

## 功能特性

- 🛒 **商店界面** - 滚动列表显示物品，支持分类筛选、搜索与排序
- 🔢 **商品顺序管理** - 管理员可在定价窗口用「置顶 / 上移 / 下移 / 置底」自定义商品陈列顺序，商店按该顺序展示，顺序随存档持久化
- 💰 **货币系统** - 通过击杀僵尸获得金钱
- 🪧 **悬浮余额面板** - 画面右侧常驻的小面板，左侧购物图标 + 右侧当前余额；点击直接开/关商店，按住可拖拽，位置随角色保存；可在模组选项里关闭
- 🔄 **死亡继承** - 玩家死亡后保留全部金钱
- 🖱️ **右键菜单** - 在世界界面或物品栏中右键点击，选择"打开商店"（默认关闭，可在模组选项里开启）
- ⌨️ **可配置快捷键** - 打开商店与商品管理都支持自定义键位（默认不绑定，在 选项 → 模组 → 简易商店 中配置）
- 🌍 **多语言支持** - 内置中英文界面
- ⚙️ **可配置** - 支持自定义初始金钱和物品价格
- 🏷️ **游戏内定价** - 管理员可在游戏内从全部物品脚本（含其他模组物品）中选择物品并设定售价，价格随存档持久化

## 安装方法

### Steam 创意工坊安装
1. 订阅 [SimpleShop 模组](https://steamcommunity.com/sharedfiles/filedetails/?id=3619356125)
2. 在游戏启动器中选择模组
3. 启动游戏

## 使用方法

### 打开商店
- **悬浮余额面板**: 画面右侧常驻一块「购物图标 + 余额」的小面板，默认在右边中间；左键点一下开/关商店，按住拖动可换位置（位置记在角色 ModData 里，下次进游戏还在原处；分辨率变化会自动收回画面内）
- **右键菜单**: 在世界界面或物品栏中右键点击，选择"打开商店"（默认关闭，在 选项 → 模组 → 简易商店 里勾选「显示「打开商店」右键菜单」才会出现）
- **快捷键**: 可在 选项 → 模组 → 简易商店 里自行绑定（默认不设置，见下方"快捷键"）

### 购买物品
1. 打开商店界面
2. 点击要购买的物品
3. 点击"购买"按钮
4. 物品将直接添加到你的物品栏

### 物品筛选与排序
- **搜索功能**: 使用搜索框快速查找所需物品
- **分类筛选**: 使用下拉菜单按类别浏览物品
- **排序方式**: 顶部与分类、搜索同一行的排序下拉框默认是 **商店顺序**（管理员在定价窗口里调整的陈列顺序），也可临时切换为 **名称 A→Z / 名称 Z→A / 价格 低→高 / 价格 高→低**，排序与搜索、分类筛选可叠加；当前结果数量显示在窗口顶部玩家名右侧，切换排序时已选中的物品保持不变

### 商品定价（管理员）
1. 先在世界设置里开启沙箱选项 **简易商店 → 允许配置商品**（默认关闭，见下方"沙箱选项"）
2. 在 选项 → 模组 → 简易商店 里勾选 **显示「管理商品」按钮**（本机开关，默认关闭；不勾选的话窗口底部没有按钮，只能用快捷键打开定价窗口）
3. 以管理员身份进入游戏（单人存档默认即为管理员）
4. 打开商店窗口，点击底部 **管理商品** 按钮；或按 **管理商品的快捷键**（默认不绑定）
5. 在弹出的「商品定价」窗口中：
   - 顶部工具栏：搜索框（按物品名称或物品 ID 如 `Base.Axe` 过滤）、**已上架商品 / 全部物品** 视图切换
   - 默认视图为 **已上架商品**：每行带绿色 **已上架** 徽标与当前价格，选中即可直接改价或下架
   - 第二行是两级筛选加排序：先选 **来源模组**（原版 / 各模组），再从 **物品类型** 里选具体类别，第二个下拉只列出所选模组的类型；第三个下拉默认 **商店顺序**，也可切换 **名称 A→Z / Z→A / 价格 低→高 / 高→低**（价格视图下未上架的物品统一排在最后）
   - 切到 **全部物品** 可浏览全部物品脚本（**包含其他模组添加的物品**），同样支持两级筛选与分页
   - 列表只收录真实可用的物品脚本：`Hidden` / `Obsolete` 物品，以及模组内部使用的 `xxx_Hidden` 变体（同一件衣服的内部样式副本，显示名与本体完全相同）不会出现在列表里
   - 列表支持分页（每页条数按窗口高度自动计算），底部显示 `页码 X / Y` 与当前过滤结果总数
   - 选中物品 → 输入价格（0 ~ 999999 的整数）→ 点击 **上架/改价**；**下架** 移出商店；**恢复默认** 重置为 `SimpleShopItems.lua` 的初始清单
6. 定价结果立即生效，已打开的商店窗口会自动刷新

### 商品顺序管理（管理员）
- 顶部工具栏右侧的 **置顶 / 上移 / 下移 / 置底** 按钮可调整选中商品在商店里的陈列顺序（只对已上架商品生效）
- 列表在 **商店顺序** 模式下会在名称前显示序号（`1.`、`2.` …），调整后立刻能看到结果；如果当前是名称/价格排序，点按钮会自动切回商店顺序再调整
- 新上架的商品自动排到顺序末尾；下架的商品自动从顺序里移除；**恢复默认** 会同时清空自定义顺序，回到按名称排列
- 从未调整过顺序时，商店按名称排列（与旧版本行为一致），第一次调整（上移/下移/置顶/置底）会把当时的名称顺序固化为自定义顺序

**持久化说明**：价格表与商品陈列顺序保存在同一个世界级全局 ModData（键名 `SimpleShopPrices`，字段 `prices` / `order`）中，随存档保存，重启游戏/换角色都不会丢失；联机时由服务端权威写入并同步给所有客户端；购买金额按该价格表结算。

### 模组选项（本机设置，改完立即生效）
位置：主菜单或游戏内 选项 → 模组 → 简易商店，写入 `Zomboid/Lua/ModOptions.ini`。

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 显示悬浮余额面板 | 开启 | 画面右侧「购物图标 + 余额」的小面板；关掉后立即移除，重新勾选立即出现（位置仍沿用上次拖拽的位置） |
| 显示「打开商店」右键菜单 | 关闭 | 世界/物品栏右键里的「打开商店」选项；开启后才有，关掉时用悬浮面板或快捷键打开 |
| 显示「管理商品」按钮 | 关闭 | 商店窗口底部是否显示按钮，点应用/确定后立即生效（已打开的商店窗口会自动重建） |
| 打开商店的快捷键 | 未绑定 | 点击按钮后按下想用的键即可；想取消按 Esc / 清空该条目 |
| 管理商品的快捷键 | 未绑定 | 同上，且需要沙箱开启「允许配置商品」 |

> 「显示管理按钮」只是本机偏好，**按钮真正出现还要求世界沙箱选项开启「简易商店 → 允许配置商品」**（两者是与关系）。选项页顶部有这条提示。

- 按键只在玩家存活时生效；聊天框/输入框正在打字时会自动屏蔽快捷键，避免误触发

### 沙箱选项（世界级，默认关闭）
选项定义在 `common/media/sandbox-options.txt`，运行时读取 `SandboxVars.SimpleShop.*`：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `AllowManageItems` | 关闭 | 是否允许配置商品（定价 / 陈列顺序）。关闭时按钮、快捷键、联机改价请求全部拒绝 |

- **单人**：新建世界时在「沙箱选项 → 简易商店」页里设置（旧存档若之前没这个选项，需要能改沙箱设置的场合才会补上默认值，否则保持关闭）
- **联机**：服务端在 `Server/<存档名>_SandboxVars.lua` 或管理面板的「沙箱选项」里修改，重启/重载后生效，客户端自动同步；服务端也会据此拒绝改价请求
- 关闭时玩家只看得见商店、买不了也改不了，适合纯消费型服务器

### 获得金钱
- 击杀僵尸：每杀死一个僵尸获得金钱奖励
- 初始金钱：新角色开始时有100初始资金

## 配置选项

模组支持以下配置（位于 `common/media/lua/shared/`）：

```lua
SimpleShopBasic = {
    ["initialMoney"] = 100, -- 初始金钱
    ["zombieKillAmount"] = 10, -- 每击杀一个僵尸获得的金钱
}

SimpleShopItems = {
    -- 基础生存物资
    ["Base.Bread"] = 75,               -- 面包
    ["Base.Apple"] = 25,               -- 苹果
    ["Base.Milk"] = 60,                -- 牛奶
    -- 医疗用品
    ["Base.Bandage"] = 150,            -- 绷带
    ["Base.PillsBeta"] = 200,          -- 药片
    ["Base.Disinfectant"] = 180,       -- 消毒剂
    -- 工具
    ["Base.Hammer"] = 300,             -- 锤子
    ["Base.Axe"] = 500,                -- 斧头
    ["Base.Saw"] = 400,                -- 锯子
    ["Base.Screwdriver"] = 200,        -- 螺丝刀
    -- 武器
    ["Base.BaseballBat"] = 400,        -- 棒球棒
    -- 建筑材料
    ["Base.Nails"] = 50,               -- 钉子
    -- 弹药
    ["Base.Bullets9mmBox"] = 100,      -- 9mm子弹盒
    ["Base.Bullets38Box"] = 175,       -- .38子弹盒
    ["Base.Bullets44Box"] = 190,       -- .44子弹盒
    ["Base.308Box"] = 300,             -- .308子弹盒
    ["Base.ShotgunShellsBox"] = 450,   -- 霰弹枪子弹盒
    ["Base.Bullets45Box"] = 500,       -- .45子弹盒
    ["Base.556Box"] = 600,             -- 5.56子弹盒
}
```

> 说明：游戏内定价过的价格会写入存档中的价格表（全局 ModData `SimpleShopPrices`），优先级高于 `SimpleShopItems.lua`。修改 `SimpleShopItems.lua` 只影响"首次加载"和"恢复默认"时的初始清单。

## 开发信息

### 技术栈
- **编程语言**: Lua
- **游戏引擎**: Project Zomboid
- **UI框架**: ISUI (游戏内置UI系统)

### 主要功能模块

1. **商店系统** (`SimpleShop.lua`)
   - 货币管理
   - 事件处理
   - 玩家数据持久化
   - 打开入口：悬浮余额面板（默认开启）/ 右键菜单（默认关闭）/ 可配置快捷键（默认不绑定）
   - 悬浮余额面板的创建、位置持久化（玩家 ModData 的 `SimpleShopHudX/Y`）与金额千分位格式化

2. **用户界面** (`ISSimpleShop.lua` / `ISSimpleShopAdmin.lua`)
   - 滚动列表显示
   - 物品分类、搜索与排序（商店顺序 / 名称 / 价格，排序逻辑在 `SimpleShopDataManager`，两个界面共用）
   - 物品选择交互
   - 购买逻辑
   - 商品定价（已上架视图带徽标/价格与顺序序号、全量物品搜索 + 模组/类型两级筛选 + 排序 + 分页、改价/下架/恢复默认、置顶/上移/下移/置底调整陈列顺序）

3. **价格与顺序持久化** (`SimpleShopItemStore.lua`)
   - 世界级全局 ModData（`SimpleShopPrices`）存储价格表（`prices`）与陈列顺序（`order`）
   - 主控端写入，其余端只发请求
   - 变化监听器（界面自动刷新）

4. **结算与同步** (`SimpleShopServer.lua` / `SimpleShopClientCommands.lua`)
   - 购买金额按价格表重算，拒绝客户端伪造金额
   - 定价与调序操作的权限校验（仅管理员可改价/调序）

5. **配置系统** (`SimpleShopBasic.lua` / `SimpleShopItems.lua`)
   - 基础设置
   - 默认物品清单（仅在首次创建价格表或"恢复默认"时使用）

## API接口

SimpleShop提供了以下API，供其他mod调用以修改玩家金钱：

### 获取玩家当前金额
```lua
SimpleShop.GetPlayerMoney(playerIndex)
```
获取指定玩家的当前金额，不指定playerIndex则获取当前玩家金额。

### 增加玩家金额
```lua
SimpleShop.AddPlayerMoney(amount, playerIndex)
```
为指定玩家增加金额，amount必须为正数。

### 减少玩家金额
```lua
SimpleShop.RemovePlayerMoney(amount, playerIndex)
```
从指定玩家扣除金额，amount必须为正数且玩家余额必须足够。

### 检查玩家是否有足够金额
```lua
SimpleShop.HasEnoughMoney(amount, playerIndex)
```
检查指定玩家是否有足够金额。

这些方法可用于实现任务奖励、自定义商店等需要修改玩家金钱的功能。
